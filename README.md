# Healthcare Fraud, Waste & Abuse Analytics

## Overview

This project focuses on analyzing synthetic healthcare claims and provider-level data to identify unusual billing patterns and potential Fraud, Waste, and Abuse (FWA) indicators.

The project demonstrates how data analytics techniques can be used to examine healthcare claims, understand provider behavior, detect unusual patterns, and prioritize records for further investigation.




## Business Problem

Healthcare organizations process large volumes of claims, making it difficult to manually identify every unusual billing pattern.

Data analytics can help identify potential areas of concern by analyzing claim frequency, reimbursement amounts, procedure patterns, provider behavior, and deviations from normal or peer-level patterns.

## Objectives

- Analyze healthcare claims and provider behavior.
- Identify unusual billing and reimbursement patterns.
- Detect potential duplicate and abnormal claims.
- Compare provider-level activity and payment behavior.
- Develop analytical indicators for potential FWA investigation.
- Build interactive visualizations for healthcare analytics.
- Provide actionable insights for further investigation.

## Key Areas of Analysis

- Provider billing behavior
- Claim frequency analysis
- Procedure utilization
- Reimbursement analysis
- High-value claim detection
- Duplicate claim identification
- Provider-level anomaly detection
- Peer-group comparison
- Potential FWA indicators
- Provider risk analysis
